  UI 脚本结构

  用户管理.py
  ├── 文件头注释（用法、依赖）
  ├── CONFIG（URL、凭证，可从外部覆盖）
  ├── PLAYBOOK（从 playbook.json 内嵌）
  ├── 内置 Helper（~150 行）
  │   ├── wait_for_dialog()
  │   ├── fill_form()
  │   ├── click_confirm_dialog()
  │   ├── find_row_and_hover_dropdown()
  │   ├── select_row_checkbox()
  │   ├── assert_success_message()
  │   └── auto_login()  ← 运行时提供自动登录
  ├── run_operation()  ← 执行单个操作的步骤序列
  └── main()           ← 入口（argparse + playwright 启动）

  登录逻辑：
  - 脚本内嵌简化版 auto_login()（用户名+密码+点击登录）
  - 如果检测到滑块验证码，调用 lib/auth.py 的登录函数（运行时增强）
  - Cookie 过期时用户可以手动改 CONFIG 中的凭证重跑
