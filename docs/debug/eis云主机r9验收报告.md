## 三、5 个终败根因定案

### P1 重置密码 dialog_still_open——登录名 name_pattern 错值（新发现，最高优先级）
- 证据链：4 轮填充的登录名全为 name_pattern 新生成值（test596039/test596115/test596135/test596957/test596977），而该云主机实际登录名 = **test595047**（创建轮 L171：登录名 = test595047）。
- **error 通知在填充时即出现**（每轮 3 字段填充后、点确定前即出现 3 条"修改云主机密码失败"，全日志共 30 次）——EIS 重置密码弹窗每字段 blur 触发 API 校验，登录名不存在即报错 → 提交必然失败、弹窗不关 → 守卫 B dialog_still_open **判定正确**（真实业务失败，非假失败）。
- 对比：重装操作系统弹窗同样填 name_pattern 登录名（test595569）却成功——重装会重置系统、允许任意新登录名；重置密码要求登录名与 OS 现有用户匹配。业务语义差异所致。
- 修复方向：重置密码类弹窗的"登录名"回显/凭证字段回填行实际值（marker 派生：EIS 创建时登录名=名称）或优先保留字段 currentValue，而非 name_pattern 生成。

### P2 创建镜像 dialog_mismatch——修复 3a 归属判据过严误杀
- 证据链：点"创建镜像"菜单 → 打开的弹窗 title='**创建云主机镜像**'（操作名中插了"云主机"，'创建镜像'**不是**其连续子串）→ 3a 判据（btn 文本是 title 子串）不命中 → 误判"上一操作残留弹窗"→ **强制隐藏了本操作自己的弹窗** → 4 次尝试全 dialog_mismatch → 入册 terminal_failed_operations。
- 修复方向：3a 判据放宽——支持子序列匹配（删除"云主机"等主体词后比对）或 token 重叠率；防误杀真实弹窗。

### P3 网络配置 no_submit_button——generic 跳转型操作缺 F6 导航成功判定
- 证据链：点"网络配置"菜单 → 页面跳转 virtualManage → vmDetail/...（期望 URL 完全一致）→ 但 generic 路径走 EDIT-FLOW 新页面探索 → 详情页 9 个 tab 点击全部 5s 超时（EIS 详情页 tab 结构特殊）→ submitLikeBtns(0) → no_submit_button × 2 轮终败。
- 修复方向：F6（url_before 接线 navigation_url_change 判成功）扩展到 generic 角色的跳转型操作——检测到 URL 跳转且含 marker 时直接判导航成功，不走找提交按钮路径。

### P4 退出运维模式 click_failed——业务成功被判定失败（成功信号优先级缺陷）
- 证据链：点菜单 → **捕获成功通知"已退出运维模式"**（L4261，total=1）→ confirm_dialog 点确定后 2s，verifier 读到 DOM field 红字"密码不能为空"（全日志唯一一次，疑似空标题弹窗内密码字段校验或残留弹窗红字）→ 第 1 轮判 field 失败 → 第 2/3 轮菜单项 visible=not_found（**退出成功后菜单项消失，恰是成功的佐证**）→ click_failed 终败。
- **业务实际成功**（成功通知 + 菜单项消失双重佐证），运行维模式镜像操作（进入）无红字干扰判成功。
- 修复方向：verifier 裁决规则——已捕获 success 通知时不应被 DOM field 红字推翻；或互斥对操作菜单项消失视为成功信号。

### P5 标签管理 click_failed——菜单项时序漂移
- 证据链：行菜单展开 22 项，option_text='标签管理' visible=not_found（2 轮均如此）。收集入册时该菜单项可见，执行时不可见——菜单项随行状态/运维模式动态显隐，收集快照与执行时态漂移。属收集层固有时序问题，低频可接受，暂不修。
