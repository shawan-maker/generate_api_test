## 三、6 个问题定案

### P1（最高优先级）守卫 B 假失败——弹窗滞留判定不消费已捕获 success 消息
- 证据链（重装）：第 1 轮主提交点确定 → 500ms 守卫 B 判 dialog_still_open（11:36:52）→ **判定 1 秒后**捕获 success「操作系统已重装」（11:36:53）→ 第 2 轮重试提交收 error「volume不存在」→ 证明第 1 轮提交已真实生效（volume 进入重建流程）。三批完全同构（11:42:16→11:42:17、11:44:50→11:44:51）。
- 证据链（快照）：**success 先于判定到达**——提交 11:37:42 → 捕获「创建快照成功」11:37:43 → 守卫 B 仍判 dialog_still_open 11:37:44（消息已在数组 total=2，守卫完全无视）。三批共创建 3 个快照烧满配额，后续「已存在3个快照」error 又被同路径循环。
- 与 F9 的关系：F9 修正的是 generic 确认弹窗尾链「红字早退」，不覆盖 submit_form_v2 守卫 B 这一层——守卫 B 只看弹窗指纹，消息裁决序修正未接线到该早退点。
- 弹窗滞留本身：快照弹窗提交后「二轮兜底后弹窗仍可见」，属 EIS 前端异步关闭慢（>500ms）/不自动关闭行为。
- 修复方向：守卫 B 判 dialog_still_open 前先消费消息数组——已有 success 语义通知则改判成功（或交 verifier 裁决）；500ms 窗在二次确认场景延长至 success/error 消息到达或弹窗实际关闭。配额类 error（「上限为3」）应进状态性豁免表，避免无意义重试。

### P2 退出运维模式收集缺口 → 运维模式锁死 → 5 操作连锁失败
- 证据链：进入运维模式 main 成功（11:34:10）→ 菜单文本翻转（11:35:08 起所有下拉清单实证「退出运维模式」visible disabled=False）→ 翻转后唯一一次 INCREMENTAL-SCAN 触发（11:47:10，查看详情成功触发）**has_visible_menu=False 作废**（dispatchEvent 展开索引 3 未打开行菜单，只看到残留弹窗的取消/确定按钮，26 个行操作全部误报「消失」）→ new_buttons=[] → 「退出运维模式」终身未入册（4 次「发现新启用按钮」批清单均无它）。
- r9 对照：同通道 16:56:25 成功捕获 new_buttons=['退出运维模式']——**本次为扫描可靠性时序问题，非批七代码回归**（通道逻辑未变）。
- 连锁后果（maintenance=True 持续到运行结束）：删除 skipped（按钮 disabled）、暂停 reconcile 轮 2 次 not_found（菜单 21/22 项，运维模式下暂停项消失）、执行命令 Running 期仍 disabled、恢复失去 Paused 路径。
- 修复方向：①增量扫描 has_visible_menu=False 时不作废——重试展开（换 vue_show/hover 策略）或延迟一轮再扫；②互斥对翻转检测在「进入运维模式成功」时即预约一次定向扫描（不等下一个 generic 成功触发）。

### P3 更新密钥对 no_confirm_button——el-select 值同步校验失败 + 否定前缀拦截后无退路
- 证据链：el-select「密钥对」4 步点选全成功（multi_step R1）→ 值同步校验失败判「填充 密钥对 失败」（Vue model 未随选项点击更新）→ 无可填字段走直接提交 →「更新」命中否定前缀「放弃更新」被 F4 正确拦截 → footer primary「更新并重启云主机」因 model 未更新保持 disabled → 无结构化确认按钮可点 → no_confirm_button 终败（131s）。
- 定性：F4 拦截正确（r9 旧路径误点工具栏「更新」按钮的假成功已被堵死），暴露的真缺口是 el-select 选项点选后 Vue model 值同步——EIS 该组件可能需要 native change/dispatchEvent 同步或 input 事件触发。
- 修复方向：el-select 选项点击后补 Vue model 同步探测（对比点击前后 model 值），失败时用 dispatchEvent 补发 change；值同步失败不应走「无可填字段直接提交」。

### P4 恢复 click_failed——结构性依赖（低优先级）

### P5 标签管理 click_failed——Running 态菜单项时序依赖（r9 P5 同型）

### P6 执行命令 skipped——前置条件从未满足（低优先级）
- 3 次预检均 Vue disabled：main 轮 Stopped 态禁用（业务规则）；reconcile 轮 11:49:51/11:55:19 Running 期仍 disabled——重装 ×3 后 qga agent 可能未就绪（qgaReady 待查），或运维模式下执行命令被禁。预检拦截本身正确（省 3 次盲试）。
